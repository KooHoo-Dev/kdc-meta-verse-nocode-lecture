## 5. 총과 입력을 나눴습니다 (결정 10) ✅ 반영 완료

### 왜 나눴나

VR 에서 예전 `SimpleGun` 을 그대로 쓰면 두 군데가 어긋났습니다.

| 예전 코드 | VR 에서 |
| :--- | :--- |
| `Update()` 가 **마우스를 직접 읽음** | 총을 안 쥐어도 마우스 클릭이면 발사됩니다 |
| `GetAimDirection()` 이 **화면 한가운데로 조준** | 총알이 **총구가 아니라 보는 쪽**으로 갑니다 |

두 번째가 특히 문제입니다. **총을 쥐는 의미가 사라집니다.**

### 나눈 결과

```
Gun (빈 그릇)
├── SimpleGun      총알을 내보내는 부품      ← 22 ~ 27차시 · 32차시 모두
└── MouseShooter   마우스로 겨누고 쏘는 부품  ← 22 ~ 27차시만
                   32차시에서 이걸 떼어냅니다
```

| 부품 | 하는 일 **하나** |
| :--- | :--- |
| **`SimpleGun`** | 총알을 만들어 **`Muzzle Point` 가 향한 쪽으로** 내보낸다 |
| **`MouseShooter`** | 총을 **십자선 쪽으로 돌려놓고**, 마우스를 누르면 `Fire` 를 불러준다 |

**`MouseShooter` 의 Inspector 항목**

| 항목 | 뜻 | 조작 |
| :--- | :--- | :--- |
| `Aim At Crosshair` | 총을 십자선 쪽으로 돌려놓기 | 체크 |
| `Aim Distance` | 얼마나 멀리 있는 점을 겨눌지 | 숫자 |
| `Fire Button` | 어느 마우스 버튼으로 쏠지 | **목록에서 고르기** |
| `Hold To Fire` | 누르고 있으면 계속 쏘기 | 체크 |

> ✅ **설명이 한 문장으로 줄었습니다**
>
> *"총알은 총구가 향한 쪽으로 나갑니다."* — 예외가 없습니다.
> 예전 교안은 이 대목을 *"여기가 조금 까다로운 부분입니다"* 로 시작해야 했습니다.

### VR 쪽은 새 부품이 없습니다

`XR Grab Interactable` 의 **`Activated`(썼다)** 칸에 **`SimpleGun.Fire`** 를 연결합니다.
`Fire()` 가 인자 없는 동작이라 목록에 그대로 뜹니다.

> 📝 **원래 계획했던 `VRGunHandler` 는 취소했습니다**
>
> `plans/02` 는 *"`Activated` 에 `SimpleGun.Fire` 를 연결하는 얇은 어댑터"* 로 적어뒀는데,
> 그 연결은 **어댑터 없이 그냥 됩니다.** 정작 막던 건 조준 방향이었고, 그건 부품 분리로 풀렸습니다.
>
> 그리고 31차시가 이미 *"오늘 안 쓴 **썼다**로 방아쇠를 당깁니다"* 라고 예고해뒀습니다.
> **`Activated` 이벤트를 쓰는 것 자체가 32차시의 교육 내용**이라, 부품으로 가리면 손해입니다.

| | 안 | 내용 | 비용 |
| :---: | :--- | :--- | :--- |
| **가** | **화면을 3D 물건으로 바꾼다** | 점수 · 시간은 **사격장 벽에 붙은 판** 하나로, 난이도 · 시작은 **3D 토글 버튼**으로. `World Space` 를 «판을 세상에 세운다» 한 문장으로 넘김 | 32차시 한 차시 |

| **다** | **32차시를 빼고 31차시에서 끝낸다** | — | **5개 차시를 고쳐야 합니다** (아래) |

> 💡 **«가» 를 추천합니다**
>
> 사용자께서 26차시 검증 때 이미 같은 생각을 하셨습니다 —
> *"VR쪽에서는 UI 말고 3D상태에서 특정 토글버튼을 조작하는걸로 생각했었는데"*.
>
> 그리고 **VR 에서 화면에 붙은 UI 는 원래 안 좋은 방식**입니다.
> 눈앞에 판이 떠 있으면 어지럽습니다. **세상 안에 놓는 게 VR 의 방식**이에요.
> 즉 이건 «어쩔 수 없이 바꾸는 것» 이 아니라 **가르칠 만한 내용**입니다.

## 6-3. «한손사격» 은 32차시 조건입니다 (2026-08-24 확정)

커리큘럼 29차시 칸의 **«한손사격»** 은 **29차시 내용이 아니라 32차시 설계 메모**입니다.

> ✅ **32차시의 총은 «한 손으로» 잡고 쏩니다**
>
> | | |
> | :--- | :--- |
> | **왜** | **XR Simulator 로 원활하게 시험하기 위해서.** 양손 총은 시뮬레이터에서 다루기 어렵습니다 |
> | **무엇이 필요한가** | 총을 **한 손으로 잡고 그 손으로 쏘는 것**까지. 양손 파지는 **안 만듭니다** |
> | **29차시 교안** | **그대로 둡니다.** 지금대로 이동 · 둘러보기만 다룹니다 |

**흐름상으로도 맞습니다.** 31차시에서야 «물체 잡기» 를 가르치는데
29차시에 총을 쥐게 하면 30 · 31차시를 건너뛰었다 되돌아오는 모양이 됩니다.
