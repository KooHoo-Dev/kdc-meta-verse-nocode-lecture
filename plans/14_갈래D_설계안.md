# 갈래 D 설계안 — 32 · 33차시 VR 클레이 사격

> 커리큘럼이 배정한 두 차시의 **실습 구성과 변환 방식**을 확정합니다.
> 범위 근거는 `plans/08` §6-1 · §6-2 · §6-3.
> 작성: 2026-08-24

---

## 1. 먼저 — 새로 만들 부품이 없습니다

**컴파일로 확인했습니다.** 32차시가 필요로 하는 셋이 **XRI 기본 부품으로 전부** 됩니다.

| 필요한 것 | 무엇으로 | 새 부품 |
| :--- | :--- | :---: |
| **3D 물건을 «누르기»** (시작 · 난이도) | `XR Simple Interactable` 의 **`Select Entered`** | ❌ 불필요 |
| **총을 한 손으로 잡고 쏘기** | `XR Grab Interactable` 의 **`Activated`** ▸ `SimpleGun.Fire`<br/>`Select Mode` = **`Single`**(한 손) | ❌ 불필요 |
| **화면을 세상 안에 세우기** | `Canvas` 의 **`Render Mode` = `World Space`** | ❌ 불필요 |

> ✅ **24차시의 설계가 여기서 값을 합니다**
>
> `SimpleGun` 과 `MouseShooter` 를 나눠뒀기 때문에
> 32차시가 하는 일은 **«입력 부품 하나를 떼고, 이벤트 하나를 거는 것»** 이 전부입니다.
>
> 24차시 교안이 예고한 그대로예요 —
> *"32차시에서 이 총을 VR로 옮길 때, **떼어낸 그 자리에 손이 들어옵니다.**"*

## 2. 27차시 완성 씬을 무엇으로 바꾸나

| 27차시에 있는 것 | 32차시에서 | 왜 |
| :--- | :--- | :--- |
| `Player` (`PlayerMover` · `CapsuleCollider` · `Rigidbody`) | ❌ **버립니다** | `XR Origin` 이 몸을 대신합니다 |
| `Main Camera` (`MouseLook`) | ❌ **버립니다** | 고개를 돌리는 건 고글이 합니다 |
| **`Gun`** (`SimpleGun`) | ✅ **씬으로 꺼내** 받침대에 올려둡니다 | **집어야** 하니까요 |
| `MouseShooter` | ❌ **뗍니다** | 마우스로 겨누지 않습니다 |
| `Crosshair` (십자선) | ❌ **버립니다** | VR 은 십자선을 안 씁니다. **총구가 곧 조준선**입니다 |
| `ScoreText` · `TimeText` | 🔄 **세상 안의 판**으로 | 화면에 붙은 것은 고글에서 안 보입니다 |
| `StartPanel` (버튼 4 · 글자 1) | 🔄 **3D 물건**으로 | 커리큘럼 원문이 *"게임 시작 **오브젝트**"* |
| `Launcher` · `StartZone` · `GameManager` | ✅ **그대로** | 손댈 것이 없습니다 |
| `Ground` · `Fence` · `BGM` · 표적 틀 · 총알 틀 | ✅ **그대로** | 〃 |

> 🚨 **화면에 붙은 것은 고글에서 안 보입니다**
>
> 22 ~ 27차시의 화면은 전부 **`Screen Space - Overlay`** 입니다.
> **고글 흉내 부품의 Game 창에서는 보이지만, 실제 고글에서는 안 보입니다.**
>
> 30차시까지는 시뮬레이터로 확인하는 차시라 문제가 없었습니다.
> **32차시는 «완성본» 이라 여기서 정리해야 합니다.**

## 3. 32차시 — VR 클레이 사격 #1

> 커리큘럼 원문 — *"**게임 시작 오브젝트**, **사냥용 총**을 가상현실 환경에 맞게 **재구성** 해본다"*

### 실습 구성

| 실습 | 무엇 | 회수하는 것 |
| :---: | :--- | :--- |
| **①** | **몸을 바꿔 끼우기** — `Player` 를 지우고 `XR Origin` 을 놓습니다 | 28차시 «틀 하나면 VR 이 된다» |
| **②** | **총을 손에 쥐기** — `Gun` 을 씬으로 꺼내고 `MouseShooter` 를 떼고 잡히게 만듭니다 | 31차시 «잡았다» |
| **③** | **방아쇠 당기기 (핵심)** — `Activated` ▸ `SimpleGun.Fire` | 24차시 «부품 하나는 일 하나만» |
| **④** | **화면을 세상 안으로** — 점수판을 벽에 붙이고, 시작 · 난이도를 3D 물건으로 | 17차시 «앵커» 의 반대편 |

### 실습 ③이 이 차시의 봉우리입니다

**칸 하나를 거는 게 전부입니다.**

```
XR Grab Interactable
└── Activated (썼다)  ──→  SimpleGun.Fire
```

31차시가 예고해둔 그대로입니다 —
*"오늘 배운 **잡았다** 로 총을 쥐고, 오늘 안 쓴 **썼다** 로 방아쇠를 당깁니다."*

### 판단한 것

| | 정한 것 | 왜 |
| :--- | :--- | :--- |
| **총을 어디에 두나** | **받침대에 올려둡니다** | 31차시가 «잡기» 를 가르쳤습니다. **집는 동작 자체가 교육 내용**입니다 |
| **한 손 / 두 손** | **한 손** (`Select Mode` = `Single`) | 사용자 결정 — **시뮬레이터로 시험할 수 있어야** 합니다 (`plans/08` §6-3) |
| **이동 방식** | 걷기 · 순간이동 **둘 다 그대로** | `XR Origin` 틀에 이미 들어 있습니다. **손댈 것이 없습니다** |
| **점수판 자리** | 사격장 **앞쪽 울타리 위**, 표적이 날아오는 쪽 | 표적을 보면서 점수도 보이게 |

## 4. 33차시 — VR 클레이 사격 #2

> 커리큘럼 원문 — *"**Prefab** 을 활용하여 **여러 클레이 사격장**이 구성된 **게임월드**를 구성해본다"*

### 실습 구성

| 실습 | 무엇 | 회수하는 것 |
| :---: | :--- | :--- |
| **①** | **무엇을 틀에 넣을까** — 사격장을 하나로 묶습니다 | 14차시 «묶으면 한 몸» |
| **②** | **틀로 만들기 (핵심)** — 사격장 하나를 통째로 붕어빵 틀로 | 15차시 «틀 하나로 다섯 대» |
| **③** | **여러 개 놓아 게임월드** — 틀 하나를 고쳐 전부 바꾸기 | 15차시 실습 ③ |
| **④** | **사격장마다 다르게 (선택)** — 한 곳만 어렵게 | 15차시 실습 ④ «하나만 따로» |

### 이 차시의 진짜 내용은 «무엇을 틀에서 뺄까» 입니다

사격장을 통째로 복제하면 **겹치면 안 되는 것**이 딸려옵니다.

| 부품 | 여러 개면 | 틀에 |
| :--- | :--- | :---: |
| 바닥 · 울타리 · 발사기 · 받침대 · 총 | 사격장마다 하나씩 있어야 **맞습니다** | ✅ **넣습니다** |
| **`HitScorer`** (점수 담당) | 🚨 **심판이 둘이면 경기가 안 됩니다** | ❌ **뺍니다** |
| **`RoundTimer`** (제한 시간) | 시간이 여러 개면 어느 게 진짜인지 모릅니다 | ❌ **뺍니다** |
| **`GameStarter`** · **`DifficultyPreset`** | 시작이 여러 개면 헷갈립니다 | ❌ **뺍니다** |

> ✅ **25차시가 여기서 완결됩니다**
>
> 25차시에 «심판은 씬에 하나» 를 배웠고,
> «틀은 씬 안의 물건을 가리킬 수 없다» 도 배웠습니다.
>
> **33차시는 그 두 문장이 왜 그랬는지가 눈앞에 펼쳐지는 차시입니다.**
> 사격장을 세 개 놓아보면 **점수 담당을 왜 하나만 둬야 했는지** 몸으로 알게 됩니다.

### 판단한 것

| | 정한 것 | 왜 |
| :--- | :--- | :--- |
| **사격장 몇 개** | **세 개**를 나란히 | 하나는 원본, 둘은 복제. **«전부 바뀐다» 가 보이는 최소 개수**입니다 |
| **난이도는 어떻게** | 사격장마다 **발사기 값을 다르게** (쉬움 · 보통 · 어려움) | `DifficultyPreset` 은 발사기를 **하나만** 가리킵니다. 값을 틀에 박는 쪽이 깔끔하고, **15차시 실습 ④(하나만 다르게)의 회수**가 됩니다 |
| **점수는 합산되나** | ✅ **네.** 어느 사격장에서 맞혀도 **같은 심판**에게 갑니다 | 그게 «심판은 하나» 의 결과입니다 |

## 5. 작업 순서

| 단계 | 무엇 | 산출물 |
| :---: | :--- | :--- |
| **1** | **32차시 교안** | `32_vr_clay_shooting_nocode.md` |
| **2** | **32차시 VOD** | `32_vr_clay_shooting_vod_script.md` |
| **3** | **33차시 교안** | `33_vr_clay_world_nocode.md` |
| **4** | **33차시 VOD** | `33_vr_clay_world_vod_script.md` |
| **5** | **빌더 2개 + 체인** | `Build32VrClayShooting` · `Build33VrClayWorld` · `BuildVrClayChain` |

### 진행 상황

| 단계 | 상태 |
| :---: | :--- |
| **1 · 2** | ✅ **32차시 교안 · VOD 완료** — 10구간 50분 · 실습 ①②③④ 일치 · 금지어 0 |
| **3 · 4** | ✅ **33차시 교안 · VOD 완료** — 9구간 50분 · 실습 ①②③④ 일치 · 금지어 0 |
| **5** | ✅ **코드 완료 · 검증 대기** — `Build32VrClayShooting` · `Build33VrClayWorld` · `BuildVrClayChain` |

> 🚨 **빌더를 만들면서 찾은 것 — `Player` 를 지우면 연결 두 줄이 끊깁니다**
>
> 26차시가 `On Game Start` 에 여섯 줄을 걸어뒀는데, 그중 둘이
> **`MouseLook.LockCursor`** 와 **`PlayerMover.EnableMove`** 입니다. 둘 다 `Player` 안에 있어요.
> `On Game End` 의 `UnlockCursor` · `DisableMove` 도 마찬가지입니다.
>
> 32차시가 `Player` 를 지우면 **네 줄이 «대상 없음» 으로 남습니다.**
> 돌아가는 데 지장은 없지만 **점검기가 «끊어진 연결» 로 짚습니다.**
>
> → `BuildKit.DropBrokenListeners` 를 만들어 **빌더가 치우게** 했고,
> **교안 두 곳**(실습 ① 트러블슈팅 · §11 흔한 실수)에도 안내를 넣었습니다.
>
> 그래서 개수가 이렇게 됩니다 —
> **32차시** `On Game Start` **4** · `On Game End` **2**
> **33차시** 각각 **6** · **4** (사격장 둘을 더해서)

> 🚨 **32차시 교안에 순간이동 바닥 단계를 넣었습니다**
>
> 33차시 교안이 *"31차시에 바닥을 순간이동 목적지로 만들어두셨죠"* 라고 썼는데,
> **31차시 씬과 32 · 33차시 씬은 계열이 다릅니다.**
> 32차시는 `27_완성` 에서 출발하므로 그 바닥에는 아무것도 안 붙어 있습니다.
>
> → **32차시 실습 ①에 4단계(바닥을 순간이동 목적지로)를 추가**하고,
> 33차시의 그 문장을 **«32차시에»** 로 고쳤습니다.
>
> 사격장이 **가로 50미터**라 걸어서만 다니면 느립니다. 33차시에서 셋이 되면 더 그렇고요.

> 📝 **`BuildKit` 에 두 가지를 더했습니다**
>
> | 무엇 | 왜 |
> | :--- | :--- |
> | `WireVoid(UnityEventBase, UnityAction)` | `Activated` · `Select Entered` 는 **인자를 넘겨주는 칸**이라 기존 `Wire` 로는 안 걸립니다. 인자 없는 `Fire` · `StartGame` 을 걸려면 이 길이 필요합니다 |
> | `DropBrokenListeners(UnityEventBase)` | 대상이 사라진 줄을 치웁니다 |

> 📝 **33차시 설계를 글 쓰면서 한 군데 고쳤습니다 — 울타리를 틀에서 뺐습니다**
>
> 처음 설계는 «사격장 전체» 를 틀에 넣는 것이었는데, 쓰다 보니 막혔습니다.
>
> **22차시 울타리는 높이가 `3` 입니다.** 눈높이(`1.6`)보다 높아요.
> 사격장마다 울타리가 딸려오면 **옆 사격장으로 못 걸어갑니다.**
> 커리큘럼이 말한 *"여러 클레이 사격장이 구성된 **게임월드**"* 가 안 됩니다.
>
> → **틀에는 «사대 바닥 + 발사기» 만** 넣습니다. 울타리는 **바깥 하나**로 전체를 감쌉니다.
>
> 그러면서 **`RangeFloor`(사대 바닥)** 를 새로 만들게 했습니다.
> 사격장이 여럿이면 **어디가 어딘지 보여야** 하고, 실습 ④에서 **곳마다 색을 다르게** 하는 데도 쓰입니다.

> ✅ **32차시 교안에 함정 두 개를 더 넣었습니다**
>
> | 함정 | 왜 |
> | :--- | :--- |
> | **총을 먼저 꺼내야 합니다** | `Gun` 이 `Player ▸ Main Camera` 안에 있습니다. `Player` 를 그냥 지우면 **총도 사라집니다** (14차시 «부모가 사라지면 자식도») |
> | **잡으려면 부딪히는 몸이 필요한데 24차시에서 지웠습니다** | 총알이 총에 맞아 사라져서요. **손잡이 쪽만** `Size 0.12, 0.14, 0.4` 로 다시 붙입니다. 총구 앞을 덮으면 24차시 문제가 재발합니다 |

> 📝 **문서를 먼저 쓰는 이유**
>
> 22 ~ 27차시와 갈래 A · C 는 **교안이 이미 있어서** 빌더가 그걸 따라갔습니다.
> 갈래 D 는 **교안이 없습니다.** 빌더가 따라갈 원본이 먼저 있어야 합니다.
