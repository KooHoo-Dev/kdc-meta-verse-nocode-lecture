## A. XR 교안 확정 — 🟨 12곳

### ~~Q1. 걷기 부품을 끄면 `W A S D` 가 멈추나요?~~ ✅ **29차시 마감**

**답: 멈추지 않습니다.** `Dynamic Move Provider` 를 꺼도 `W A S D` 는 그대로 움직입니다.

**시뮬레이터의 `W A S D` 가 기기 자체를 옮기기** 때문입니다. 게임의 걷기 부품을 거치지 않아요.
**고글을 손으로 들고 옮기는 것**에 가깝습니다.

**반영 결과**

| | |
| :--- | :--- |
| 실습 ③ 껐다 켜기 | **`Turn` (`Snap Turn Provider`)** 으로 교체 — 차이가 확실히 보임 |
| 교안에 추가 | *"`Move` 를 꺼도 `W A S D` 는 움직입니다. 그게 정상이에요"* + 흉내 부품 ↔ 진짜 고글 비교표 |
| §6.1 표 | `Move` 는 **찾아만 봄**, `Turn` 이 **껐다 켬** 담당으로 정정 |

> **29차시 🟨 0곳.** 28차시와 함께 마감 완료.

> ⚠️ **같이 발견된 것 — 부품 위치가 교안과 달랐습니다**
>
> 이동 부품들은 맨 위가 아니라 **`XR Origin (XR Rig)` ▸ `Locomotion`** 안에 **종류별로 나뉘어** 있습니다.
>
> ```
> Locomotion
> ├── Move            ← Dynamic Move Provider
> ├── Turn            ← Snap Turn + Continuous Turn (둘 다 여기)
> ├── Teleportation   ← Teleportation Provider
> └── Grab Move · Gravity · Jump
> ```
>
> 교안이 *"맨 위 `XR Origin` 조종석을 내려보면 보인다"* 로 되어 있어 **실습 ③·④가 성립하지 않았습니다.**
> 교안 5곳 · VOD 4곳을 고쳤고, VOD 에는 **"일부러 한 번 못 찾는"** 시연으로 넣었습니다.

### ~~Q2. 물건을 잡는 키가 무엇인가요?~~ ✅ **`G` (Grip)**

**답** — `]`(또는 `[`) 로 손을 고른 뒤, **`G` 를 누른 채로** 잡고 **떼면** 놓습니다.

| 하고 싶은 것 | 키 |
| :--- | :--- |
| 오른손 / 왼손 고르기 | **`]`** / **`[`** |
| **잡기** | **`G` 를 누른 채로** (Grip) |
| **놓기** | **`G` 를 떼기** |

**토글이 아니라 누르고 있는 방식**입니다. 손으로 물건을 쥐는 것과 같아요.

> 시뮬레이터 조작 안내(**`X`**)에 `Trigger T` · **`Grip G`** · `Primary 1` · `Secondary 2` 로 적혀 있습니다.
> 왼손은 **`Shift` + 같은 키** 로도 됩니다.

**반영** — 31차시 실습 ③ 1·2단계, VOD 시연 A·B, 실습 순서 블록에 `G` 로 확정.

### ~~Q6. 360 사진의 임포트 설정이 무엇인가요?~~ ✅ **손댈 것 없음**

**답: 바꿀 것이 없습니다.** `Texture Shape` 이 **`2D`** 로 들어오고, 그대로 쓰면 됩니다.

| 항목 | 확인된 값 |
| :--- | :--- |
| `Texture Type` | `Default` |
| **`Texture Shape`** | **`2D`** ✅ 그대로 |
| **`Max Size`** | **`2048`** |
| `Compression` | `Normal Quality` |

> 📝 **`Max Size` 는 강의자료를 2K 로 맞추면 문제없습니다**
>
> 확인에 쓰신 파일이 **`valley_of_desolation_2k`** 였고, `Max Size` 기본값과 일치합니다.
>
> **4K 를 배포하시면** 여기서 절반으로 줄어듭니다. 그때는 교안에 한 단계를 넣어야 해요.
> → **2K 로 배포하시는 쪽을 권합니다.** 배경이라 티가 안 나고 용량도 가볍습니다.

**반영** — 교안을 *"`2D` 인지만 확인, 바꿀 것 없음"* 으로 단순화하고,
흐릴 때만 보라고 `Max Size` 를 **`!!! tip`** 으로 내렸습니다.
**VOD 에는 `Max Size` 를 언급하지 말라고 지시**했습니다 — 말하면 만지다 망가집니다.

### Q9. `SkyboxSwitcher` 가 실제로 동작하나요? 🟠

**왜 묻나요** — 제가 이번에 새로 만든 부품인데 **에디터에서 한 번도 안 돌려봤습니다.**

**선행** — Q6·Q7 로 **하늘 재료를 2개 이상** 만들어두셔야 합니다. (사진만 바꿔서 반복)

#### 순서

**1.** Hierarchy 우클릭 → `Create Empty` → 이름 **`WorldManager`**

**2.** **`Add Component`** → **`Skybox Switcher`** 검색해서 추가
→ 목록에 **`NoCode Kit`** 분류로 들어가 있습니다.

**3.** **`Skyboxes`** 오른쪽 숫자를 **`2`** 로 올립니다. (또는 `+`)
→ 칸이 두 개 펼쳐집니다. 각각 채웁니다.

| 칸 | 넣을 것 |
| :--- | :--- |
| `Label` | **`노을`** 처럼 한글로 |
| `Material` | Q7 에서 만든 하늘 재료 |

**4.** Hierarchy 우클릭 → `UI` → **`Button - TextMeshPro`**
→ 처음이면 **TMP Essentials 임포트 창**이 뜹니다. `Import` 눌러주세요.

**5.** 버튼의 **`On Click ()`** 에서 **`+`** → **`WorldManager`** 를 왼쪽 칸에 드래그
→ 오른쪽 목록에서 **`SkyboxSwitcher`** → **`Next`**

**6.** **▶** 를 누르고 버튼을 **두 번** 눌러봅니다.
→ 첫 번째에 두 번째 하늘로, 두 번째에 **다시 처음 하늘로 돌아와야** 합니다. (순환)

**7.** (여유 되시면) `Text - TextMeshPro` 를 하나 놓고,
`WorldManager` 의 **`On Skybox Changed`** → `+` → 그 글자를 드래그 → **`TextMeshProUGUI`** → **`text`**
→ ⚠️ 목록에서 **`Dynamic string`** 쪽을 고르셔야 합니다.
