**왜 막아두었나** — 두 폴더의 문서에 **🟨 표시(미확정 지점)** 가 남아 있습니다.
`🟨 U-7 5-7 결과로 확정` 같은 내부 작업 메모라, 수강생 화면에 나가면 안 됩니다.

!!! ⚠️ 막지 않으면 '반쯤 공개' 됩니다
    `exclude_docs` 없이 두면 **좌측 메뉴에는 안 보여도** 페이지는 생성되고
    **사이트 내 검색과 `sitemap.xml` 에 그대로 올라갑니다.** 검색엔진도 색인합니다.
    메뉴에서 빼는 것(`.pages`)만으로는 가려지지 않습니다.

## 2. 공개 절차 — 순서를 지키세요

### 0단계 — 먼저 확인

- [ ] 해당 폴더에 **🟨 가 0개**인가 (`grep -rc "🟨" "Docs/1. NoCode/4. 사격장/"`)
- [ ] 교안마다 **VOD 스크립트 짝**이 있는가 (22~27은 아직 없습니다)

### 1단계 — `mkdocs.yml` 의 `exclude_docs` 에서 줄 삭제

```yaml
exclude_docs: |
  .idea/
  *.tmp
  4. 사격장/      ← 공개할 폴더의 이 줄을 지웁니다
  5. XR/
```

### 2단계 — 루트 `.pages` 의 nav 주석 해제

`Docs/1. NoCode/.pages` 에서 해당 줄의 `#` 을 제거합니다.

```yaml
nav:
  - '🏠 홈': index.md
  - '0. 시작하기'
  - '1. Unity 기초'
  - '2. UGUI'
  - '3. 오브젝트 다루기'
  - '4. 사격장'      ← 주석 해제
  - '5. XR'          ← 주석 해제
```

!!! danger "1단계를 건너뛰면 빌드가 깨집니다"
    `exclude_docs` 로 막힌 폴더를 nav 에 넣으면 **`NavEntryNotFound`** 로 실패합니다.
    **반드시 1단계 → 2단계 순서**로 하세요.

### 3단계 — `index.md` 강의 목록에 카드 추가

`Docs/1. NoCode/index.md` 의 `<div class="grid cards" markdown>` 안, **`3. 오브젝트 다루기` 카드 뒤**에 §3 의 블록을 붙여넣습니다.

### 4단계 — 검증

```bash
mkdocs build --strict
```

경고 0건으로 통과해야 합니다. 그다음 실제로 올라갔는지 확인합니다.

```bash
grep -c "사격장" site/sitemap.xml
```

!!! note "이 블록이 왜 여기 있나요"
    `index.md` 안에 HTML 주석으로 넣어두면 **오프라인 빌드에서 페이지 소스로 새어 나갑니다.**
