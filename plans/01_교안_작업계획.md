## 2. 기존 1~3차시 재배치

기존 3개는 그대로 옮기면 **커리큘럼 순서와 충돌**합니다. 아래처럼 재구성합니다.

| 기존 | → | 조치 |
| :--- | :---: | :--- |
| `02_unity_editor_nocode` + `_vod_script` | **13** | 파일명·차시 번호·앞뒤 예고만 수정. **본문 거의 그대로** |
| `03_scene_hierarchy_inspector_*` | **14** | GameObject·Component 개념 절 추가 + 실습 재편(아래) |
| `01_unity_engine_nocode` + `_vod_script` | **11 / 12 / 14 / 19 로 분해** | 아래 표 |

### 2-1. 기존 1차시 분해

문제: 기존 1차시는 **설치 전에 실습을 시킵니다.** 새 순서에서는 12차시가 설치이므로 성립하지 않습니다.

| 기존 1차시 요소 | 이동처 | 이유 |
| :--- | :---: | :--- |
| Unity 소개 · 영화 스튜디오 비유 · 활용 분야 · 두 얼굴 | **11** | 그대로 유지 |
| 부품 조립 개념 · 레고 비유 | **11** (개념) / **14** (실습) | 개념은 동기부여, 조작은 설치 후 |
| 설치 안내 · 버전 맞추기 | **12** | 12차시의 본론 |
| 실습 ① 빈 그릇 + 부품 붙이기 | **14** | GameObject·Component 차시에 정확히 부합 |
| 실습 ②③④ CubeSpinner 값 조작 · 버튼 연결 · On Stopped | **19** | 버튼 연결은 UGUI 영역. 19차시가 "UGUI 조합" |

### 2-2. 11차시는 실습 없는 유일한 차시

설치 전이라 **수강생이 만질 것이 없습니다.** 다음으로 50분을 채웁니다.

- 완성작 투어 (클레이 사격 · VR 클레이 사격 최종본 플레이 영상)
- Unity 소개 · 비유 · 활용 분야
- XR Interaction Toolkit **소개만** (잡기·텔레포트 시연 30초, 개념 설명 없음)
- 전체 커리큘럼 로드맵 = **"오늘부터 33차시까지 이렇게 갑니다"**
- 12차시 설치 예고

> `!!! info` 문구를 이 차시만 바꿉니다: "오늘은 **보기만 하시면 됩니다.** 설치는 다음 시간에 같이 합니다."

## 3. 작업 배치 (Batch)

**Unity 프로젝트 선행 여부**로 묶었습니다. 🔴 구간은 프로젝트가 먼저 나와야 교안을 쓸 수 있습니다.

### Batch A — 재배치 + 기초 (11 · 12 · 13 · 14)

| 항목 | 내용 |
| :--- | :--- |
| 신규 작성 | 11, 12 |
| 재배치 | 13(수정 소), 14(수정 중) |
| Unity 선행 | `ConsoleTester` · `CubeSpinner` **2개뿐** — 이미 명세 확정됨 |
| 병목 | 11차시 완성작 투어 영상 → **클레이 사격 완성 후에나 녹화 가능**. 교안은 먼저 쓰고 영상 지시만 비워둠 |

### Batch B — UGUI · 기본 컴포넌트 (15 ~ 21)

| 항목 | 내용 |
| :--- | :--- |
| 원본 상태 | 17·19·20·21 충분 / 15·16·18 부분 |
| Unity 선행 | 프리팹 샘플 세트, 교육용 컴포넌트 4개 (`RendererSwitcher` `ValueDisplay` `TransformDriver` `CollisionReporter`) |
| 특이사항 | 15차시 **프리팹 = "붕어빵 틀"** 비유 확정 필요. 어휘집에 먼저 등재 |
| 21차시 범위 | 시트가 **"Tag까지만"** 으로 못 박음. Layer·Raycast·물리 재질 전량 제외 |

### Batch C — 클레이 사격 (22 ~ 27) ★ 최대 병목

| 항목 | 내용 |
| :--- | :--- |
| 원본 | 사실상 전무 |
| 성격 | **교안 집필 = 게임 제작**. 실습 ③ 6개가 곧 게임의 6개 마일스톤 |
| Unity 선행 | 교육용 컴포넌트 **12개** + 프리팹 세트 + 씬 1개 |
| 작업 방식 | **차시별로 "그 시점의 프로젝트 스냅샷"** 이 필요합니다. 22차시 끝 상태 = 23차시 시작 상태 |
| 권장 순서 | Unity에서 게임을 **끝까지 한 번 완성** → 6개 마일스톤으로 역분할 → 교안 집필 |

### Batch D — XR (28 ~ 31)

| 항목 | 내용 |
| :--- | :--- |
| 원본 | 31 충분 / 28·29 얇아서 보강 필요 / 30 없음 |
| Unity 선행 | XRI 패키지 설치 + XR Interaction Simulator 샘플 + XR Origin 프리팹 |
| **설계 전제 (확정)** | **Simulator 는 강사의 녹화 환경**입니다. **수강생 실습은 선택**이고, **실기기 화면은 별도 동영상**으로 제공합니다. 전제는 **"Simulator 로 한손 권총 클레이 사격을 테스트"** → 착수를 막는 검증 항목은 **없습니다** |
| 28차시 주의 | 원본에 Unity 2022.3 LTS·Meta SDK 등 **시효성 정보**가 박혀 있음 → 버전 번호 제거하고 "강의자료 안내 버전" 으로 대체 |

### Batch E — VR 클레이 사격 (32 · 33)

| 항목 | 내용 |
| :--- | :--- |
| 선행 | Batch C 완료 + Batch D 완료 |
| 성격 | C의 결과물을 XR로 **재구성**. 새 게임이 아님 |
| 33차시 핵심 | 프리팹으로 사격장을 **복제**해서 여러 개 배치 → 15차시 프리팹 개념의 회수 지점 |
