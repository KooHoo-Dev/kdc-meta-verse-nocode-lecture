## 0. 시작 전 확인

### 0-1. 환경 (이미 확인됨)

| 항목 | 상태 |
| :--- | :--- |
| Unity 에디터 | `6000.3.15f1` — 프로젝트 버전과 **일치** |
| 스크립트 컴파일 | 에러 없음 |
| `.meta` 파일 | **23개 전부 커밋·푸시 완료** — 이 PC에서 열어도 GUID 안전 |
| 입력 방식 | **새 Input System 전용** (`activeInputHandler: 1`) |

### 0-2. ⚠️ XR 을 먼저 꺼주세요

**클레이 사격은 비VR 씬입니다.** 그런데 지금 프로젝트는 **XR 이 켜져 있습니다.**

`Assets/XR/XRGeneralSettingsPerBuildTarget.asset` 의 **`Initialize XR on Startup` 이 켜져 있어서**,
▶ 를 누를 때마다 OpenXR 을 초기화하려 합니다. 콘솔 경고가 쌓이고 카메라가 이상하게 잡힐 수 있습니다.

**U-6 작업 전에 꺼두세요.**

1. `Edit` → `Project Settings` → **`XR Plug-in Management`**
2. **`Initialize XR on Startup`** 체크 **해제** (또는 `OpenXR` 체크를 통째로 해제)

> **28~31차시로 돌아가실 때 다시 켜시면 됩니다.** 설정만 바뀌는 거라 되돌리기 쉽습니다.

### 0-3. 만들기 전에 알아둘 것

!!! warning "Tag는 씬을 만들기 **전에** 등록하세요"
    나중에 하면 프리팹을 다시 열어 하나씩 지정해야 합니다.

    `Edit` → `Project Settings` → `Tags and Layers` → `Tags` 에서 **두 개**를 추가합니다.

    | Tag | 붙일 대상 | 읽는 부품 |
    | :--- | :--- | :--- |
    | `Target` | Target 프리팹 | `Projectile` 의 `Target Tag` |
    | `Bullet` | Bullet 프리팹 | `Hittable` 의 `Hitter Tag` |

    `Player` 는 **Unity 기본 Tag라 이미 있습니다.** 새로 만들지 마세요.

    설계 문서 §3-3 에는 `StartZone` Tag 도 적혀 있지만, **어떤 컴포넌트도 이 Tag를 읽지 않습니다.**
    (`GameStarter` 는 자기에게 **들어온 쪽**의 Tag를 봅니다 = `Player`)
    → **만들지 않아도 됩니다.** 만들어도 해는 없습니다.

### 0-4. ★ 시간을 크게 아끼는 방법 — 마일스톤 스냅샷

설계 문서 §8 은 **"완성본을 만든 뒤 6개로 역분할"** 순서입니다.
그런데 **만들어 가면서 단계마다 `Save As` 로 복사본을 남기면** 역분할이 저절로 끝납니다.

```
M1 지점 도달 → Save As → M1_Range.unity      → 계속 이어서 만들기
M2 지점 도달 → Save As → M2_Target.unity     → 계속
...
M6 완성      → Save As → ClayShooting.unity
```

| | 역분할 (설계 문서 순서) | 스냅샷 (이 방법) |
| :--- | :--- | :--- |
| 작업량 | 완성본에서 **덜어내기 6회** | `Save As` **6회** |
| 실수 위험 | 덜 지우거나 더 지움 | 거의 없음 |
| 단점 | — | **M1~M5 의 값이 조율 전 값** |

!!! tip "단점 처리"
    값 조율(`Launch Force` · `Spread Angle` · `Bullet Speed`)은 **§3 검증 중에 확정**됩니다.
    확정된 값은 **해당 마일스톤 씬에만 다시 넣어주면** 됩니다. 항목은 서너 개뿐입니다.

    스냅샷 방식을 쓰신다면 **아래 §2 의 `📸` 표시 지점에서 저장**하세요.

## 1. 완성본이 어떤 게임인지 (한 번만 훑기)

1. 사격장에 서 있고, 걸어 다니며 마우스로 둘러봅니다
2. **시작 발판**을 밟으면 시작합니다 *(26차시에서 버튼으로 바뀝니다)*
3. 정면 **발사기**가 접시를 하늘로 쏘아 올립니다
4. 마우스 왼쪽 버튼으로 쏘고, **총알이 눈에 보이게 날아갑니다**
5. 맞으면 **접시가 터지고 점수가 오릅니다**
6. **제한 시간**이 끝나면 멈춥니다
7. 난이도에 따라 **속도 · 간격 · 퍼짐**이 달라집니다
