# **기본적인 그림자 생성 원리**
그림자의 생성 원리는 **빛과 오브젝트의 관계**에 따라 결정됨.

![Shadow 그림 1](shadow/image.png)

### **빛과 그림자의 관계**
- 빛이 물체에 닿으면, 닿은 면은 밝아지고 닿지 않는 곳은 그림자가 생깁니다.
- 빛이 직진하는 성질을 가지고 있기 때문에, **광원과 물체 사이의 공간을 차단하는 부분이 그림자를 형성**하게 됩니다.
- 그림자는 **광원의 유형**에 따라 달라집니다.

### **그림자의 주요 요소**
1. **빛의 방향 (광원의 위치와 방향)**
    - 빛이 어디에서 오는지에 따라 그림자의 길이와 형태가 달라집니다.
    - 예: 낮은 각도에서 오는 빛 → 그림자가 길어짐
2. **오브젝트의 위치와 크기**
    - 물체가 클수록 그림자도 커집니다.
    - 멀리 있는 오브젝트(그림자를 생성하는 오브젝트와 그림자가 지는 오브젝트간의 거리)의 그림자는 퍼지고 흐려집니다.
3. **광원의 종류**
    - **점광원(Point Light)**
        
        > 모든 방향으로 빛이 퍼짐 → 그림자가 다방향으로 생김
        > 
    - **스포트라이트(Spot Light)**
        
        > 특정 방향으로만 빛이 나감 → 한 방향으로만 그림자가 생김
        > 
    - **평행광(Directional Light)**
        
        > 태양광처럼 빛이 한 방향에서 옴 → 그림자가 일정한 방향으로 유지됨
        >

# **게임 엔진에서 그림자가 출력되는 방식**
유니티 및 게임 엔진에서 그림자는 **쉐이더(Shader)** 와 **렌더링 기술**을 활용하여 계산됩니다.

### **그림자 생성 방식**
게임 엔진에서는 **그림자를 직접 계산하는 것이 아니라, 최적화된 알고리즘을 사용하여 렌더링** 합니다.

### **Shadow Mapping (그림자 맵핑) – 실시간 그림자**
![Shadow 그림 2](shadow/image%201.png)

**개념:**

- 광원의 시점에서 장면을 렌더링하여 깊이 정보를 저장한 후, 실제 카메라에서 이를 사용해 그림자를 생성하는 방식입니다.
- **Z-버퍼**(깊이 버퍼, Depth Buffer)를 사용하여 물체의 깊이를 비교합니다.

**과정:**

1. **광원의 위치에서 씬을 렌더링하여 깊이 값을 저장** → "Shadow Map" 생성
2. **현재 카메라에서 오브젝트의 픽셀이 광원에 의해 가려졌는지 확인**
    - 그림자 맵과 비교하여 픽셀이 가려졌다면 그림자로 표시
3. **그림자 적용**
    - 그림자가 있는 곳은 어둡게 처리 (Shading)

**장점:**

- 실시간으로 움직이는 오브젝트의 그림자를 반영 가능
- 다양한 빛의 방향과 복잡한 그림자 표현 가능

**단점:**

- 그림자 품질이 그림자 맵 해상도에 의해 결정됨 (계단현상 발생)
- Shadow Acne(그림자 깨짐 현상) 발생 가능

---

### **Lightmapping (광원 베이킹) – 정적인 그림자**
![Shadow 그림 3](shadow/image%202.png)

**개념**

- 미리 계산된 빛과 그림자를 텍스처에 저장하여 **정적인 그림자를 표현**하는 방식입니다.
- 주로 **건물, 바닥, 환경 등 움직이지 않는 오브젝트**에 사용됩니다.

**과정:**

1. 씬의 광원 정보를 기반으로 **그림자를 미리 렌더링**하여 텍스처로 저장
2. 게임 실행 시 **저장된 그림자를 사용**하여 빠르게 렌더링

**장점**

- 퍼포먼스가 뛰어남 (미리 계산된 그림자를 사용하므로 연산 부담 없음)
- 매우 부드러운 그림자 표현 가능

**단점**

- 실시간 그림자처럼 움직이는 오브젝트에는 적용 불가
- 변경이 필요한 경우 다시 베이킹 필요
- 유니티에서는 **Progressive Lightmapper, Enlighten** 등의 시스템을 사용하여 Lightmap을 생성함.

---

### **Screen Space Shadows & SSAO (스크린 공간 그림자 & 환경 그림자)**
> 이런게 있다 정도만 이해하고 넘어가면됨
> 
- **스크린 공간 그림자(Screen Space Shadows)**:
    - 카메라에서 보이는 오브젝트에 한해 그림자를 추가하는 기법
    - 최적화가 필요할 때 사용
- **SSAO(Screen Space Ambient Occlusion)**:
    - 주변 물체가 빛을 가리는 정도를 계산하여 그림자를 표현
    - 작은 오브젝트의 그림자를 표현하는 데 효과적

---

## **그림자 출력 시 발생하는 문제와 해결 방법**
게임 엔진에서 그림자는 최적화와 품질 문제를 고려해야 합니다.

### **Shadow Acne (그림자 깨짐 현상)**
- 원인: Shadow Map의 정밀도 부족으로 발생하는 Z-파이팅 문제
- 해결책:
    - **Shadow Bias** 값을 조정하여 그림자가 너무 가깝거나 멀어지지 않도록 조절
    - **PCF(Percentage Closer Filtering)** 사용하여 그림자 부드럽게 처리

### **그림자 계단 현상 (Aliasing)**
- 원인: Shadow Map 해상도가 낮거나, 텍스처 샘플링이 부족할 때 발생
- 해결책:
    - **고해상도 Shadow Map 사용**
    - **Soft Shadows 적용** (그림자 필터링 사용)

### **퍼포먼스 문제 (그림자 최적화)**
- 해결책:
    - **CSM (Cascaded Shadow Maps) 사용** → 멀리 있는 그림자의 해상도를 낮춤
    - **Lightmap 사용** → 정적 오브젝트는 미리 계산된 그림자를 활용
    - **필요한 오브젝트에만 그림자 적용** (Layer-based Shadow 설정)

---

## **결론**
- 그림자는 **Shadow Mapping, Lightmapping, SSAO** 등의 기법을 사용하여 표현됨.
- 실시간 그림자는 **Shadow Map** 기반으로 렌더링되며, 성능과 품질을 조절하는 것이 중요함.
- 최적화 기법을 활용하여 **그림자의 품질과 성능을 적절히 조정**해야 함.

# **Renderer 컴포넌트의 그림자 관련 프로퍼티**
> 엔진에서 확인해보는게 좋음
> 

Renderer 컴포넌트에서 그림자 설정을 조정하는 주요 프로퍼티는 다음과 같습니다.

| **프로퍼티** | **설명** |
| --- | --- |
| **Cast Shadows** | 오브젝트가 그림자를 생성할지 여부 설정 |
| **Receive Shadows** | 오브젝트가 다른 오브젝트의 그림자를 받을지 여부 설정 |
| **Shadow Bias** | 그림자가 오브젝트와 너무 가까워질 때 조정하는 값 |
| **Shadow Normal Bias** | 그림자의 표면 방향과 관련된 왜곡을 방지하기 위한 값 |
| **Shadow Near Plane Offset** | 그림자가 카메라에서 너무 가까운 경우 발생하는 문제를 해결하는 값 |

---

## **Cast Shadows (그림자 생성 여부)**
> Renderer.castShadows
> 
> 
> `MeshRenderer`, `SkinnedMeshRenderer` 등에서 설정 가능
> 

**역할**

이 설정을 통해 **오브젝트가 그림자를 생성할지 여부를 결정**할 수 있습니다.

**설정 값**

- **Off** → 그림자를 생성하지 않음
- **On** → 그림자를 생성함
- **Two Sided** → 양면 그림자를 생성 (사용 시 성능에 영향)
- **Shadows Only** → 오브젝트 자체는 렌더링되지 않지만 그림자만 표시됨

**활용 팁**

- **성능 최적화:** 배경 오브젝트나 작은 오브젝트는 `Off`로 설정하여 불필요한 그림자 연산을 줄일 수 있음.
- **특수 효과:** `Shadows Only`를 사용하여 유령 같은 효과 연출 가능.

---

## **Receive Shadows (그림자 받기 여부)**
> Renderer.receiveShadows
> 

**역할**

이 옵션을 활성화하면 **해당 오브젝트가 다른 오브젝트의 그림자를 받을 수 있도록 설정**합니다.

**설정 값**

- **true** → 다른 오브젝트의 그림자를 받을 수 있음
- **false** → 다른 오브젝트의 그림자를 받지 않음

**활용 팁**

- 성능 최적화를 위해 작은 오브젝트(예: 풀, 작은 소품)에서는 `false`로 설정하는 것이 좋음.
- 배경 오브젝트가 그림자를 받을 필요가 없을 경우 `false`로 설정하여 GPU 부담을 줄일 수 있음.

---

## **Shadow Bias (그림자 오프셋 조정)**
> Light.shadowBias
> 
> 
> Light.shadowNormalBias
> 

**역할**

그림자가 오브젝트와 너무 가깝거나 멀리 떨어져 있는 경우 조정하여 **Z-파이팅(깜빡이는 현상)이나 그림자 누락을 방지**할 수 있습니다.

**설정 값**

- **Shadow Bias** → 기본값 `0.05` (낮출수록 그림자가 근접)
- **Shadow Normal Bias** → 기본값 `0.4` (낮출수록 그림자가 정확해짐)

**활용 팁**

- **Z-Fighting 해결:** Shadow Bias 값을 증가시키면 그림자가 물체에 너무 가까워지는 문제를 줄일 수 있음.
- **그림자 디테일 최적화:** Shadow Normal Bias 값을 조정하여 부드러운 그림자 경계를 조정 가능.

---

## **Shadow Near Plane Offset (카메라 근처의 그림자 문제 해결)**
> Light.shadowNearPlaneOffset
> 

**역할**

그림자가 카메라에서 너무 가까운 위치에서 사라지는 경우 **이 값을 조정하여 해결**할 수 있습니다.

**설정 값**

기본값 `0.2` (높이면 가까운 그림자가 더 선명하게 유지됨)

**사용 예시:**

```csharp
myLight.shadowNearPlaneOffset = 0.1f;
```

**활용 팁**

- **카메라 근처의 그림자가 사라지는 문제 해결**
- 너무 높은 값으로 설정하면 반대로 원하지 않는 그림자가 나타날 수 있음 → 적절한 값을 찾아야 함

## **Quality Settings에서의 그림자 옵션**
Renderer에서 조정하는 옵션 외에도 **Unity의 QualitySettings** 를 사용하여 글로벌 그림자 설정을 조정할 수 있습니다.

**그림자 거리 설정**

> QualitySettings.shadowDistance
> 
- 그림자가 표시되는 최대 거리를 설정합니다.
- 멀리 있는 오브젝트에 그림자가 필요 없을 경우 이 값을 줄이면 성능이 향상됩니다.

```csharp
QualitySettings.shadowDistance = 50f;  // 그림자가 50m까지만 표시됨
```

**Shadow Cascades (그림자 계층화)**

> QualitySettings.shadowCascades
> 
- 그림자를 거리에 따라 다르게 처리하여 계단 현상을 줄이는 기술
- 기본값: `2` 또는 `4` 단계 사용 가능

```csharp
QualitySettings.shadowCascades = 4;  // 그림자를 4단계로 나눠 정밀하게 처리
```

**활용 팁**

- **Shadow Distance를 줄이면 성능이 좋아짐** (멀리 있는 그림자는 제거)
- **Cascaded Shadow Maps를 활용하면 그림자의 품질을 향상** 시킬 수 있음

---

## **결론**
유니티의 Renderer 컴포넌트에서는 다음과 같은 **그림자 관련 설정**을 조정할 수 있습니다.

1. **Cast Shadows** → 오브젝트가 그림자를 생성할지 여부
2. **Receive Shadows** → 다른 오브젝트의 그림자를 받을지 여부
3. **Shadow Bias & Normal Bias** → 그림자 위치와 왜곡 조정
4. **Shadow Near Plane Offset** → 카메라 근처의 그림자 문제 해결
5. **Quality Settings** → Shadow Distance & Cascades 조정
