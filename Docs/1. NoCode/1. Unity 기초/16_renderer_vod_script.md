# **[00:03 ~ 00:08] 화면에 그리는 부품에도 종류가 있습니다**

🖥 **화면**: 교안 1번 표

🗣
> "14차시에 **보이는 부품**을 붙여서 네모를 나타나게 하셨죠. Mesh Renderer 라고 했던 거요.
> 그런데 화면에 그리는 부품이 **그것만 있는 게 아닙니다.**
>
> **Mesh Renderer** 는 **입체 모양**을 그립니다. 자동차, 건물, 캐릭터 같은 거요.
> **Sprite Renderer** 는 **납작한 그림**을 그립니다. 2D 게임 캐릭터나 아이콘 같은 거고요.
> **Particle System** 은 **흩날리는 효과**를 그립니다. 불, 연기, 폭발 같은 겁니다."

🗣
> "공통점이 하나 있어요. **셋 다 '화면에 그려주는 일'을 합니다.** 방식만 다를 뿐이에요.
>
> 그래서 **셋 다 떼면 안 보이고, 붙이면 보입니다.** 14차시에 배운 그대로죠."

🗣
> "그럼 왜 굳이 나눠져 있을까요. **잘하는 일이 다르기 때문**입니다.
>
> 입체를 그리는 건 **계산이 많이 듭니다.** 납작한 그림이면 충분한데 입체를 쓰면 낭비예요.
> 불이나 연기처럼 **작은 알갱이가 수백 개** 필요한 건 또 다른 방식이 훨씬 유리하고요.
>
> 지금은 **'목적에 맞는 걸 고른다'** 정도만 아시면 됩니다."

- 세 가지를 말할 때 **오프닝에서 보여준 전환 장면을 짧게 다시** 띄워주면 이해가 빠릅니다.

# **[00:08 ~ 00:16] 껐다 켜기 — 두 가지 방법의 차이**

✂️ **구분 자막**: `① 안 보이게 하는 두 가지 방법`

🖥 **화면 전환**: **Unity Editor로 전환**

## **시연 (00:08 ~ 00:13)**

**1. 큐브 + 바닥 만들기**

🗣
> "먼저 큐브 하나 만들고요. 그리고 **바닥**도 하나 만들겠습니다.
> 우클릭, 3D Object, **Plane**. 위치를 0, -1, 0 으로 내려두겠습니다.
>
> 바닥이 있어야 **그림자가 보입니다.** 이따 쓸 거예요."

**2. Mesh Renderer 체크 해제**

🗣
> "큐브를 고르고, 조종석에서 **Mesh Renderer 체크를 꺼보겠습니다.**
>
> **안 보이죠?** 그런데 왼쪽 목록을 보세요. **큐브는 그대로 있습니다.**
> **몸만 없어진 겁니다.** 자리는 그대로예요."

**3. 물건 자체 체크 해제 → 이름 흐려짐 확대**

🗣
> "이번엔 다른 방법입니다. 조종석 **맨 위, 이름 왼쪽**에 체크가 하나 더 있어요. 이걸 꺼보겠습니다.
>
> **똑같이 안 보입니다.** 그런데 차이가 있어요. 목록을 보세요.
> **이름이 흐려졌습니다.**
>
> 이건 **통째로 없는 셈 치는 것**입니다. 부딪히지도 않아요.
> 아까 건 **'몸만 안 보이게'**, 이건 **'통째로 치우기'** 입니다.
>
> 결과가 비슷해 보이지만 **뜻이 완전히 다릅니다.** 체크 위치로 구분하세요.
> **맨 위는 통째로, 그 아래는 몸만.**"

**4. Cast Shadows Off**

🗣
> "하나 더 보여드릴게요. Mesh Renderer 안에 **Cast Shadows** 라는 게 있습니다.
> **'이 물건이 그림자를 만들지'** 를 정하는 거예요. **Off** 로 바꿔보겠습니다.
>
> **바닥의 그림자가 사라졌습니다.** 큐브는 그대로 보이는데요.
>
> **그리는 것과 그림자를 만드는 것은 따로 정할 수 있습니다.**"

- **이름이 흐려지는 순간을 확대**해서 담아주세요. 차이가 작아서 놓치기 쉽습니다.
- 그림자가 안 보이면 `Directional Light` 를 `E` 로 돌려 각도를 잡아주세요. **미리 잡아두고 녹화**하는 편이 좋습니다.

## **⏸ 실습 ① (00:13 ~ 00:16)**

🗣
> "직접 해보실 차례입니다. **영상을 잠깐 멈춰주세요.**
>
> 큐브랑 바닥 만드시고, **두 가지 체크를 각각 껐다 켜보세요.**
> **이름이 흐려지는지 아닌지**를 꼭 확인하시는 게 목적입니다.
>
> 그리고 그림자도 껐다 켜보세요. 다 하셨으면 재생을 눌러주세요."

```
실습 ①
① Hierarchy 우클릭 → 3D Object → Cube
② 우클릭 → 3D Object → Plane, Position 0, -1, 0
③ 큐브 선택 → Mesh Renderer 체크 해제 (몸만 사라짐)
④ 다시 켜고, 맨 위 이름 왼쪽 체크 해제 (이름이 흐려짐)
⑤ 다시 켜고, Cast Shadows 를 Off 로 (그림자만 사라짐)
```

# **[00:16 ~ 00:25] 재질 느낌 바꾸기**

✂️ **구분 자막**: `② 숫자 두 개로 재질이 정해집니다`

🖥 **화면**: Materials 폴더 → Create → Material

## **시연 (00:16 ~ 00:22)**

🗣
> "13차시에 색깔 재료를 만들어보셨죠. 그 재료에 **색 말고도 조절할 게 더** 있습니다.
>
> 새 재료를 하나 만들겠습니다. 이름은 MetalMat. 큐브에 끌어다 놓고요."

**Metallic · Smoothness 를 표 순서대로 시연** — 각 단계에서 **잠깐 멈춰서 보여주기**

🗣
> "조종석에 **Metallic** 이랑 **Smoothness** 라는 게 있습니다.
> **Metallic 은 금속 느낌**, **Smoothness 는 매끈한 정도**예요.
>
> 둘 다 0으로 두면 — **고무나 플라스틱처럼** 보입니다.
>
> Smoothness 만 0.9 로 올리면 — **도자기처럼 반들반들**해지죠.
>
> 여기서 Metallic 까지 1로 올리면 — **쇠처럼** 보입니다. 확 달라졌죠?
>
> 그리고 Smoothness 를 0.2 로 내리면 — **녹슨 쇠 느낌**이 납니다."

🗣
> "숫자 **두 개**만 움직였는데 완전히 다른 물질처럼 보이죠.
>
> **금속인가 아닌가, 매끈한가 거친가.** 이 두 가지로 대부분의 재질이 표현됩니다.
> 실제 게임에서도 이렇게 만들어요. 그림을 새로 그리는 게 아니라 **값을 맞추는 겁니다.**"

- 값을 바꾸는 장면은 **큐브와 Inspector가 한 화면에 같이** 보이게 배치해주세요.
- 슬라이더를 **천천히** 끌어주세요. 확 움직이면 변화가 안 보입니다.

## **⏸ 실습 ② (00:22 ~ 00:25)**

🗣
> "멈추고 직접 해보세요.
>
> 재료 하나 만들어서 큐브에 입히시고, **Metallic 과 Smoothness 를 표 순서대로** 바꿔보세요.
> 색도 같이 바꿔보시면 더 재밌습니다.
>
> **마음껏 움직여보세요.** 재료는 언제든 다시 만들 수 있습니다."

```
실습 ②
① Materials 폴더 우클릭 → Create → Material → 이름 MetalMat
② MetalMat 을 큐브에 드래그
③ Metallic / Smoothness 를 차례로
   0 / 0     → 고무·플라스틱
   0 / 0.9   → 도자기
   1 / 0.9   → 쇠
   1 / 0.2   → 녹슨 쇠
④ Base Map 색도 바꿔보기
```

 **주의**
- **빛이 없으면 금속 느낌이 안 납니다.** 씬에 `Directional Light` 가 있는지 한마디 넣어주세요:
> 🗣 "혹시 변화가 거의 없으시면, 씬에 **빛(Directional Light)이 있는지** 확인해보세요. 반사할 빛이 없으면 금속처럼 안 보입니다."

# **[00:25 ~ 00:39] 세 가지 갈아 끼우기 — 오늘의 핵심**

✂️ **구분 자막**: `③ 같은 자리, 세 가지 방식`

## **시연 — 세 가지 만들어 모으기 (00:25 ~ 00:30)**

🖥 **화면**: Hierarchy 확대

🗣
> "이제 세 가지를 한자리에 모아보겠습니다.
>
> 먼저 **빈 그릇**을 하나 놓습니다. 이름은 **Display**. 위치는 0, 1, 0 으로 띄워두고요.
> 14차시에 자동차 만들 때처럼 **부모 역할**입니다."

🗣
> "이제 Display **위에서 우클릭**해서 만들면 **자식으로 바로 들어갑니다.**
>
> 첫째, 3D Object, Cube. 이름은 **ShowMesh**.
> 둘째, 2D Object, Sprites, Square. 이름은 **ShowSprite**.
> 셋째, Effects, Particle System. 이름은 **ShowParticle**.
>
> 그리고 세 개의 위치를 전부 **0, 0, 0** 으로 맞춥니다. **같은 자리에 겹칩니다.**"

- 우클릭 위치에 따라 자식이 되기도 하고 안 되기도 합니다. **Display 이름 위에서 우클릭하는 것**을 분명히 보여주세요.

## **시연 — 부품 붙이고 연결 (00:30 ~ 00:33)**

🗣
> "이제 **Display 를 고르고**, 강의자료의 **RendererSwitcher** 를 끌어다 놓겠습니다.
>
> 조종석에 칸이 세 개 생겼죠? 여기에 **아까 만든 세 개를 각각 끌어다 놓습니다.**
>
> Mesh Object 칸에는 ShowMesh, Sprite Object 칸에는 ShowSprite, Particle Object 칸에는 ShowParticle.
>
> 14차시에 버튼 연결하듯이 **끌어다 놓기만** 하면 됩니다."

## **시연 — 목록으로 먼저 확인 (00:32 ~ 00:34)**

🗣
> "맨 위에 **Show Mode** 라는 목록이 있습니다. 여기서 골라보겠습니다.
>
> **Mesh** — 입체 네모가 보입니다.
> **Sprite** — 납작한 흰 사각형으로 바뀌었죠.
> **Particle** — 알갱이가 나옵니다.
> **None** — 아무것도 안 보이고요.
>
> 여기서 중요한 겁니다. **저 지금 ▶ 를 누르지 않았습니다.** 목록만 골랐어요.
> 이 목록은 **만드는 도중에 빠르게 확인할 때** 편합니다."

🗣
> "하나만 미리 말씀드릴게요. **흩날리는 효과는 ▶ 를 눌러야 제대로 재생됩니다.**
> 지금 멈춰 있는 것처럼 보여도 정상이에요. 이따 버튼으로 확인하겠습니다."

🗣
> "그리고 ShowSprite 를 고르고, 지난 시간에 넣어둔 **그림 파일을 Sprite 칸에 끌어다 놓겠습니다.**
> 다시 Sprite 모드로 하면 — **그 그림이 나옵니다.**"

## **시연 — 버튼 네 개로 갈아 끼우기 (00:34 ~ 00:36)**

🗣
> "그런데 실제 게임에서는 **사용자가 눌러서 바꿔야** 하잖아요.
> 그래서 이제 **버튼**을 만들어 연결하겠습니다.
>
> 지난 시간 마지막에 버튼 하나 만들어보셨죠? **오늘은 네 개입니다.**"

**1. 버튼 만들고 복제** — UI → Button - TextMeshPro → Ctrl + D ×3

🗣
> "버튼 하나 만들고, **Ctrl + D 로 세 번 복제**하겠습니다. 네 개가 됐죠.
> 겹쳐 있으니 **Pos Y** 를 60, 20, -20, -60 으로 나눠 세우겠습니다."

**2. 네 개를 각각 연결** — On Click → Display 드래그 → 동작 선택

🗣
> "이제 하나씩 연결합니다. **On Click 의 플러스**를 누르고,
> **Display 를 왼쪽 칸에 끌어다 놓습니다.** 이게 **누가**.
>
> 그리고 오른쪽 목록에서 **RendererSwitcher** 아래를 보면 —
> **ShowMesh, ShowSprite, PlayParticle, HideAll** 네 개가 다 있습니다. 이게 **무엇을**.
>
> 첫 버튼은 ShowMesh, 두 번째는 ShowSprite, 세 번째는 PlayParticle, 네 번째는 HideAll.
> 글자도 각각 '입체', '그림', '효과', '끄기' 로 바꾸겠습니다."

**3. Play → 버튼을 하나씩 클릭**

🗣
> "▶ 누르고 눌러보겠습니다. 입체. 그림. 효과. 끄기.
>
> **버튼으로 갈아 끼워집니다.**
>
> 그리고 **효과 버튼만 다릅니다.** 여러 번 눌러보세요. **매번 새로 터집니다.**
> `PlayParticle` 은 보이게 하는 것에 더해 **처음부터 다시 재생**까지 하거든요."

🗣
> "연결한 방법은 지난 시간과 **똑같았습니다.**
> **누가 — 무엇을.** 이 두 개만 고르면 끝이에요.
>
> 화면을 제대로 만드는 방법, 버튼을 예쁘게 배치하는 방법은 **17차시부터** 다룹니다.
> 오늘은 **연결하는 연습**이었어요."

 **주의 — 이 차시의 결론 지점**
- **버튼을 눌러 세 가지가 갈아 끼워지는 장면**이 이 차시 전체의 결론입니다. 네 개 다 **한 박자씩 쉬면서** 눌러주세요.
- **왼쪽 칸이 비어 있을 때 오른쪽 목록이 텅 비는 것**을 한 번 보여주고 채워주세요. 14차시에 이어 또 나오는 문의입니다.
- 납작한 그림은 **옆에서 보면 안 보입니다.** Scene 시점을 정면으로 잡아두고 녹화하세요.

## **⏸ 실습 ③ (00:36 ~ 00:39)**

🗣

# **비프로그래머 대상 표현 치환표**

전 차시에 걸쳐 적용함.

| 쓰지 말 것 | 이렇게 말할 것 |
| :--- | :--- |
| 변수, 필드 | **입력 칸**, **값** |
| 메서드, 함수 | **동작**, **기능** |
| public / private | (언급하지 않음) |
| 클래스, 인스턴스, 참조 | **끌어다 놓은 것** |
| 컴포넌트 | **부품** (영어 이름은 필요할 때만) |
| 프로퍼티 노출 | **인스펙터에 보이게 하기** |
| 이벤트 구독, 콜백 | **~할 때 같이 실행되게 연결** |
| 컴파일 | **저장하면 Unity가 알아서 반영** |
| 매개변수 | (다루지 않음) |
| 상속 | (다루지 않음) |
| 프레임 | (다루지 않음) |
| 크로스 플랫폼 | **한 번 만들면 어디든 간다** |
| 렌더링 | **화면에 그리기** |
| 빌드 | **완성해서 내보내기** |
