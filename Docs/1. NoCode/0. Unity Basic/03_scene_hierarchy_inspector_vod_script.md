# **[00:08 ~ 00:15] 세 창이 이어져 있다는 것**

✂️ **구분 자막**: `① 세 창은 같은 물건을 보고 있다`

🖥 **화면 전환**: **Unity Editor로 전환**

**1. 큐브 세 개 만들기** — Hierarchy 우클릭 → 3D Object → Cube ×3

🗣
> "큐브를 세 개 만들겠습니다. 우클릭, 3D Object, Cube. 세 번 반복합니다.
>
> 화면에는 하나만 보이시죠? **세 개가 정확히 같은 자리에 겹쳐 있어서** 그렇습니다.
> 목록을 보시면 세 개가 다 있어요. **정상입니다.**"

**2. Hierarchy에서 클릭 → Scene 테두리 + Inspector 갱신**

🗣
> "목록에서 첫 번째를 클릭해보겠습니다.
> **작업대에 테두리가 생겼고**, 오른쪽 조종석에 **값이 떴습니다.**
>
> 두 번째를 클릭하면? **조종석 내용이 바뀝니다.** 다른 물건을 보고 있는 거예요."

**3. Inspector에서 Position X 변경 → Scene 즉시 이동**

🗣
> "이제 조종석에서 위치의 X 값을 3으로 바꿔보겠습니다.
> **작업대에서 바로 옆으로 갔습니다.** 겹쳐 있던 게 떨어져 나왔죠."

**4. Scene에서 다른 큐브 클릭 → Hierarchy 강조**

🗣
> "반대로도 됩니다. 작업대에서 남은 큐브를 클릭해보면, **목록에서 그 이름이 파랗게** 됩니다.
>
> **어디서 고르든 세 창이 다 같은 물건을 보고 있습니다.** 이게 오늘 첫 번째로 잡고 갈 내용이에요."

**5. 이름 바꾸기** — F2 또는 천천히 두 번 클릭

🗣
> "그리고 하나 더. **이름을 바꾸는 습관**을 지금부터 들이시면 좋습니다.
> 목록에서 이름을 **천천히 두 번 클릭**하거나, **F2**를 누르면 바꿀 수 있어요.
>
> `Cube (1)`, `Cube (2)`, `Cube (3)` 이렇게 열 개쯤 쌓이면 **본인도 뭐가 뭔지 모릅니다.**
> 만들자마자 바꿔두세요."

# **[00:15 ~ 00:23] 옮기고, 돌리고, 키우기**

✂️ **구분 자막**: `② 작업대에서 물건 다루기`

## **시연 (00:15 ~ 00:19)**

🖥 **화면**: Scene 창 좌상단 도구 아이콘 **확대**

🗣
> "작업대 왼쪽 위에 아이콘이 줄지어 있습니다. **물건을 다루는 도구**예요. 네 개만 쓰시면 됩니다."

**1. W — 이동**

🗣
> "**W를 누르면 이동**입니다. 물건에 **색깔 화살표**가 생겼죠?
>
> 빨간 건 좌우, 초록은 위아래, 파란 건 앞뒤입니다. 잡고 끌어보겠습니다.
>
> 여기서 **오른쪽 조종석을 같이 봐주세요.** 제가 끄는 동안 **숫자가 같이 변합니다.**
> **마우스로 끄는 거랑 숫자를 치는 거랑 똑같은 일**이라는 뜻이에요."

**2. E — 회전, R — 크기**

🗣
> "**E는 회전**입니다. 화살표가 **고리**로 바뀌었죠. 잡고 돌리면 회전 숫자가 변합니다.
> **R은 크기**고요. 손잡이를 끌면 크기 숫자가 변합니다.
>
> **W, E, R.** 이 세 개만 손에 익히시면 됩니다."

**3. 몸통을 잡고 끌어서 일부러 실패하기**

🗣
> "여기서 초보자분들이 제일 많이 겪는 걸 미리 보여드릴게요.
>
> 화살표를 안 잡고 **물건 몸통을 그냥 끌면** 이렇게 **아무 데로나 훅 가버립니다.**
> 지금 저 어디로 갔는지 모르겠죠?
>
> **Ctrl + Z**. 돌아왔습니다.
>
> **반드시 색깔 화살표를 잡고** 끌어주세요. 그래야 한 방향으로만 움직입니다."

**4. Inspector에 0, 0, 0 입력**

🗣
> "그리고 정말 어디로 갔는지 모르겠을 때는, **위치를 0, 0, 0 으로** 쳐보세요.
> **정확히 한가운데로 돌아옵니다.** 이 방법 자주 쓰시게 될 거예요."

- 도구를 바꿀 때 **키보드 키를 화면 자막으로 같이 띄워주세요.** `W` / `E` / `R` 이 언제 눌렸는지 안 보입니다.
- 몸통을 끌어서 실패하는 장면은 **자르지 말고 그대로** 담아주세요. 수강생이 똑같이 겪습니다.

## **⏸ 실습 ② (00:19 ~ 00:23)**

🗣
> "멈추고 직접 해보세요.
>
> W, E, R 눌러가면서 물건을 옮기고 돌리고 키워보세요.
> **끄는 동안 오른쪽 숫자가 같이 변하는 것**을 꼭 확인해보시고요.
>
> 마음껏 망가뜨리셔도 됩니다. **Ctrl + Z 가 있습니다.**"

```
실습 ②
① 큐브 선택 → W → 빨간 화살표 잡고 끌기
② Inspector 의 Position 숫자가 같이 변하는지 확인
③ E → 고리 잡고 돌리기 (Rotation 변화 확인)
④ R → 손잡이 잡고 크기 바꾸기 (Scale 변화 확인)
⑤ Inspector 에 Position 0, 0, 0 입력 → 한가운데로
```

## **시연 — 자동차 조립 (00:25 ~ 00:30)**

🖥 **화면**: Unity Editor. **Hierarchy와 Inspector가 한 화면에 같이 보이게** 배치

**1. 빈 그릇을 부모로** — Create Empty → 이름 `Car` → Position 0, 0, 0

🗣
> "먼저 **빈 그릇**을 하나 놓겠습니다. 1차시에 만들었던 그거예요. Create Empty.
> 이름은 **Car**. 이게 **자동차 전체를 대표하는 그릇**입니다. 화면엔 안 보이죠.
>
> 위치를 0, 0, 0 으로 맞춰두겠습니다. **이거 꼭 해주세요.** 안 그러면 이따 숫자가 다 어긋납니다."

**2. 몸체** — Cube → 이름 `Body` → Car 위로 드래그 → 값 입력

🗣
> "다음은 몸체입니다. Cube 하나 만들고 이름을 **Body**로 바꿉니다.
>
> 그리고 **목록에서 Body를 Car 위로 끌어다 놓습니다.**
> 보세요, **한 칸 안으로 들어갔죠?** 이러면 묶인 겁니다. **자식이 된 거예요.**
>
> 값은 위치 0, 0.5, 0. 크기는 2, 0.5, 1. **납작한 상자 모양**이 됐습니다."

**3. 바퀴 하나** — Cylinder → 이름 `Wheel_FL` → Car 위로 드래그 → Rotation Z 90

🗣
> "이번엔 바퀴입니다. Cylinder, 원기둥을 만듭니다. 이름은 **Wheel_FL**, 앞 왼쪽 바퀴예요.
> 역시 **Car 위로 끌어다 놓습니다.**
>
> 그런데 지금 원기둥이 **서 있죠?** 이걸 눕혀야 바퀴가 됩니다.
> **회전의 Z 값을 90으로** 바꾸겠습니다. **누웠습니다.**
>
> 크기는 0.4, 0.1, 0.4. 위치는 0.7, 0.2, 0.55."

**4. 복제** — Ctrl + D ×3 → 이름과 Position만 변경

🗣
> "나머지 세 개는 **복제**하겠습니다. 하나 만들어놓고 **Ctrl + D**를 누르면 똑같은 게 하나 더 생겨요.
> 세 번 누르고, **이름과 위치만** 바꿔주면 됩니다. 회전이랑 크기는 이미 맞춰져 있으니까요.
>
> 앞 오른쪽, 뒤 왼쪽, 뒤 오른쪽. 위치 숫자는 교안 표에 정리해뒀습니다.
>
> **자동차가 됐습니다.**"

- 숫자를 입력하는 장면은 **Inspector를 크게 확대**해주세요. 기본 크기로는 어느 칸에 넣는지 안 보입니다.
- 표의 값을 하나씩 읽으면서 넣는 장면을 **다 담아주세요.** 빨리 넘기면 따라오지 못합니다.

🗣

> **Car 하나에만** 붙였습니다. 바퀴에는 안 붙였어요.

> **자동차 전체가 돕니다.** 다섯 조각이 통째로요.

>

# **비프로그래머 대상 표현 치환표**

전 차시에 걸쳐 적용함.

| 쓰지 말 것 | 이렇게 말할 것 |
| :--- | :--- |
| 변수, 필드 | **입력 칸**, **값** |
| 메서드, 함수 | **동작**, **기능** |
| public / private | (언급하지 않음) |
| 클래스, 인스턴스, 참조 | **끌어다 놓은 것** |
| 컴포넌트 | **부품** (영어 이름은 필요할 때만) |
| 프로퍼티 노출 | **인스펙터에 보이게 하기** |
| 이벤트 구독, 콜백 | **~할 때 같이 실행되게 연결** |
| 컴파일 | **저장하면 Unity가 알아서 반영** |
| 매개변수 | (다루지 않음) |
| 상속 | **묶으면 부모를 따라온다** (용어 자체는 쓰지 않음) |
| 프레임 | (다루지 않음) |
| 크로스 플랫폼 | **한 번 만들면 어디든 간다** |
| 렌더링 | **화면에 그리기** |
| 빌드 | **완성해서 내보내기** |
