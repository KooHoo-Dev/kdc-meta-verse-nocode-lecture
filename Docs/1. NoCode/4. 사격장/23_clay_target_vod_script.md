✂️ **구분 자막**: `③ 밟으면 시작됩니다`

🖥 **화면**: Unity Editor

## **시연 A — 발판 놓기 (00:35 ~ 00:37)**

**1.** `Cube` → `StartZone` → `Position` `0, 0.1, -15` / `Scale` `3, 0.2, 3` → 노란색

🗣
> "큐브를 납작하게 눌러 발판을 만들겠습니다. 이름은 **`StartZone`**.
> 위치는 플레이어와 발사기 **사이**입니다. 걸어가다 밟게요.
> 노란색을 입혀서 **여기가 시작점**이라는 걸 알려줍니다."

**2.** `Box Collider` 의 `Is Trigger` 체크

🗣
> "그리고 **`Is Trigger`** 체크. 21차시에 배운 그겁니다.
>
> 이걸 안 켜면 발판이 **밀어내서** 그 위에 올라서게 됩니다.
> 켜면 **통과하면서도 밟았다는 건 감지**돼요."

## **시연 B — 이름표 확인 (00:37 ~ 00:38)**

**3.** `Player` 선택 → `Tag` 를 `Player` 로

🗣
> "`Player` 를 고르고 **`Tag`** 를 **`Player`** 로 지정합니다.
>
> 이건 **Unity 가 미리 만들어둔 이름표**라 만들 필요 없이 **고르기만** 하면 됩니다.
> 아까 `Target` 은 직접 만드셨죠? 이건 이미 있는 거예요."

## **시연 C — 연결, 그리고 한 번 틀리기 (00:38 ~ 00:42)**

**4.** **일부러** `GameManager` 를 만들고 거기에 `GameStarter` 를 붙인 뒤 ▶ → **반응 없음**

🗣
> "빈 그릇 **`GameManager`** 를 하나 만들고, 여기에 **`GameStarter`** 를 붙여보겠습니다.
> 이름이 그럴듯하죠? 게임을 관리하는 것 같으니까요.
>
> 그리고 ▶ 눌러서 발판을 밟아보면… **아무 일도 안 일어납니다.**"

**5.** `GameStarter` 를 `StartZone` 으로 옮기기

🗣
> "왜 그럴까요. **감지는 발판이 합니다.**
>
> `GameStarter` 는 **자기에게 뭔가 들어왔는지**를 보는 부품이에요.
> `GameManager` 는 허공에 있는 빈 그릇이라 **아무도 안 들어옵니다.**
>
> **발판(`StartZone`)에 붙여야** 합니다. 옮기겠습니다."

- **틀리는 장면과 고치는 장면을 둘 다 담으세요.** '관리자니까 GameManager에' 는 아주 자연스러운 오해입니다.

**6.** `Trigger Tag` 를 `Player` 로 → `On Game Start` `+` → `Launcher` 드래그 → `StartLaunching`

🗣
> "**`Trigger Tag`** 를 **`Player`** 로 둡니다. **플레이어만 반응**하게요.
>
> 그리고 **`On Game Start`** 칸. **`+`** 누르고, **`Launcher`** 를 왼쪽에 끌어다 놓고,
> 목록에서 **`TargetLauncher`** → **`StartLaunching`**.
>
> 이 순서, **1차시부터 하나도 안 변했습니다.**"

**7.** ▶ → 발판 위로 걸어가기 → 접시가 연달아 날아옴

🗣
> "▶ 누르고… **발판 위로 걸어갑니다.**
>
> **날아옵니다.** 밟는 순간 시작됐어요."

# **비프로그래머 대상 표현 치환표**

전 차시에 걸쳐 적용함.

| 쓰지 말 것 | 이렇게 말할 것 |
| :--- | :--- |
| 변수, 필드 | **입력 칸**, **값** |
| 메서드, 함수 | **동작**, **기능** |
| public / private | (언급하지 않음) |
| 클래스, 인스턴스, 참조 | **끌어다 놓은 것** |
| 컴포넌트 | **부품** (영어 이름은 필요할 때만) |
| 인스턴스화 · 생성 | **찍어낸다** · **만들어낸다** |
| 오브젝트 풀링 | (다루지 않음) |
| 파괴 · Destroy | **사라진다** · **치운다** |
| 이벤트 구독, 콜백 | **~할 때 같이 실행되게 연결** |
| 프로퍼티 노출 | **인스펙터에 보이게 하기** |
| 컴파일 | **저장하면 Unity가 알아서 반영** |
| 매개변수 | (다루지 않음) |
| 상속 | (다루지 않음) |
| 프레임 | (다루지 않음) |
| 크로스 플랫폼 | **한 번 만들면 어디든 간다** |
| 렌더링 | **화면에 그리기** |
| 빌드 | **완성해서 내보내기** |
