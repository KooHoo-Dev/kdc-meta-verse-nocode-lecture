## 각 파일의 상태

| 부분 | 상태 |
| :--- | :--- |
| 제목 · `!!! info` · 오늘의 목표 | ✅ 확정 |
| 개념 절 | ✅ 확정 |
| 오늘 사용할 부품 표 | ✅ 확정 (컴포넌트 14개 제작 완료) |
| **실습 ①~④** | 🟨 **잠정** — U-7 결과로 확정 |
| 코드 딱 한 번 보기 | ✅ 확정 |
| 오늘 배운 것을 그림으로 | ✅ 확정 |
| 정리 문제 · 조심할 것 · 정리 · 다음 차시 · 용어 | ✅ 확정 |

실습 절 안에서 **U-7 항목에 걸린 단계**는 이렇게 표시해두었습니다.

```markdown
> 🟨 **U-7 `3-4` 결과로 확정** — 총알이 십자선 방향으로 나가는지
```
