# **[00:16 ~ 00:26] 실습 ② — 제한 시간 붙이기**

## **시연 A — 타이머 놓고 화면에 띄우기 (00:16 ~ 00:20)**

**1.** `GameManager` 선택 → `RoundTimer` 드래그 → `Duration 60` · `Auto Start` **체크 해제**

🗣
> "`GameManager` 에 `RoundTimer` 를 끌어다 놓습니다. 25차시의 그 그릇이에요.
>
> `Duration` 은 60초. 그리고 **`Auto Start` 는 체크를 풉니다.**
> ▶ 누르자마자 시작하면 안 되죠. **발판을 밟아야** 시작해야 하니까요."

**2.** `Canvas` 우클릭 → `Text - TextMeshPro` → `TimeText` (앵커 `top-center`, 한글 글꼴)
**3.** `ValueDisplay` 드래그 → `Prefix` `남은 시간: ` · `Suffix` `초`

🗣
> "화면 가운데 위에 글자를 하나. `ValueDisplay` 를 붙입니다.
> **25차시 점수판이랑 똑같은 부품**이에요. 앞뒤 글자만 다릅니다."

**4.** `RoundTimer` 의 `On Tick` 에 `+` → `TimeText` 드래그 → **위쪽 `Dynamic float`** 의 `SetValue`

🗣
> "`On Tick` 에 이어줍니다. **위쪽 `Dynamic float`.**
>

## **시연 B — 시작·종료 잇기 (00:20 ~ 00:24)**

**5.** `StartZone` 선택 → `GameStarter` 의 `On Game Start` 에 `+` → `GameManager` → `RoundTimer` → `StartTimer`

🗣
> "발판을 밟으면 **시간도 같이 흘러야** 합니다.
> `On Game Start` 에 칸을 하나 더 만들어서 `StartTimer` 를 겁니다.
>
> 여기 이미 하나가 걸려 있죠? **발사 시작.** 23차시에 거신 겁니다.
> 이제 **둘**이 됐어요."

**6.** `GameManager` 선택 → `RoundTimer` 의 `On Finished` 에 `+` → `StartZone` 드래그 → `GameStarter` → `EndGame`

🗣
> "시간이 다 되면 **게임을 끝냅니다.**
> `On Finished` 에서 `GameStarter` 의 `EndGame` 을 겁니다. **이 연결은 한 번뿐이에요.**"

**7.** `StartZone` 의 `On Game End` 에 넷을 차례로 연결

| 넣을 것 | 목록에서 |
| :--- | :--- |
| `Launcher` | `TargetLauncher` → `StopLaunching` |
| `Gun` | `SimpleGun` → `DisableFire` |
| `Player` | `PlayerMover` → `DisableMove` |
| `Main Camera` | `MouseLook` → `UnlockCursor` |

🗣
> "그리고 `On Game End` 에 **넷을 차례로** 겁니다.
> 발사 정지, 사격 금지, 이동 금지, 커서 풀기.
>
> 하나씩 `+` 를 누르고 물건을 끌어다 놓고 목록에서 고르면 됩니다.
> **네 번 같은 일을 반복**하는 거예요."

- `+` 를 누를 때마다 칸이 아래로 늘어나는 것을 **한 번은 전체 화면**으로 보여주세요.

# **비프로그래머 대상 표현 치환표**

전 차시에 걸쳐 적용함.

| 쓰지 말 것 | 이렇게 말할 것 |
| :--- | :--- |
| 변수, 필드 | **입력 칸**, **값** |
| 메서드, 함수 | **동작**, **기능** |
| public / private | (언급하지 않음) |
| 클래스, 인스턴스, 참조 | **끌어다 놓은 것** |
| 컴포넌트 | **부품** (영어 이름은 필요할 때만) |
| 프리셋 · 설정 묶음 | **값 묶음** |
| 상태 전환 | **~하면 ~하게 바뀐다** |
| 이벤트 구독, 콜백 | **~할 때 같이 실행되게 연결** |
| 프로퍼티 노출 | **인스펙터에 보이게 하기** |
| 컴파일 | **저장하면 Unity가 알아서 반영** |
