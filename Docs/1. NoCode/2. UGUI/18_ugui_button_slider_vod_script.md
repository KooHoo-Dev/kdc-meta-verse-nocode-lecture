## **Transition (00:05 ~ 00:08)**

🗣
> "버튼에 마우스를 올리면 색이 살짝 밝아지고, 누르면 어두워지죠.
> **이거 저절로 되는 게 아닙니다. 설정이에요.**
>
> Button 부품의 **Transition** 이 그걸 정합니다. 상태가 네 가지예요.
>
> **Normal** 은 평소. **Highlighted** 는 마우스를 올렸을 때.
> **Pressed** 는 누르고 있을 때. **Disabled** 는 못 누르게 막았을 때.
>
> 말로만 하면 차이가 잘 안 보이니, **아주 극단적인 색으로** 바꿔서 보여드리겠습니다."

🗣
> "이제 **슬라이더**입니다. 음량 조절처럼 **끌어서 값을 정하는** 부품이에요.
>
> 값이 네 가지 있습니다.
> **Min Value** 가장 작을 때, **Max Value** 가장 클 때, **Value** 지금 값.
> 그리고 **Whole Numbers** 를 체크하면 **정수로만** 움직입니다.
>
> 0부터 100까지, 정수로만 움직이게 맞춰두겠습니다."

🗣
> "그런데 여기서 **오늘 가장 중요한 이야기**를 드리겠습니다.
>

> 슬라이더에는 **On Value Changed**, **'값이 바뀌었을 때'** 가 있습니다.
>
> 그런데 결정적인 차이가 하나 있어요.
>
> **버튼은 '눌렸다'만 알려줍니다.**
> **슬라이더는 '지금 값이 얼마다'까지 같이 넘겨줍니다.**

> 이 차이가 이따 목록 고를 때 나타납니다. 기억해두세요."

**1. ScoreText 에 ValueDisplay 붙이기**

🗣
> "먼저 아까 만든 **ScoreText 를 고르고**, 강의자료의 **ValueDisplay** 를 끌어다 놓겠습니다.

**2. Slider 의 On Value Changed 에서 `+`**

🗣

> 플러스를 눌러 칸을 하나 만들고요.
>
> **ScoreText 를 왼쪽 칸에 끌어다 놓습니다.** 이게 **누가**."

**3. 목록에서 Dynamic float 쪽 SetValue 선택** — **목록을 크게 확대**

🗣
> "그리고 오른쪽 목록을 누르면 — **여기가 오늘의 함정입니다.**
>

>
> 그리고 **양쪽 모두에 SetValue 가 있습니다.**
>
> **반드시 위쪽, Dynamic float 의 SetValue 를 고르세요.**"

🗣
> "왜 그러냐면요.

> **위쪽은 '슬라이더가 넘겨주는 값을 그대로 받아라'** 입니다.
> **아래쪽은 '미리 적어둔 고정 숫자를 써라'** 예요.
>
> 아래쪽을 고르시면 슬라이더를 아무리 움직여도 **숫자가 안 바뀝니다.**
> 이게 오늘 문의 1위가 될 거예요."

**4. 일부러 Static 을 골라서 안 되는 것 보여주기 → Dynamic 으로 수정**

🗣
> "실제로 보여드리겠습니다. 아래쪽 Static 을 골라보겠습니다. ▶ 누르고 슬라이더를 끌면 —
>
> **안 바뀌죠. 계속 같은 숫자입니다.**
>
> 이제 위쪽 Dynamic float 으로 바꾸고 다시 해보겠습니다."

**5. Play → 슬라이더를 끌어 숫자가 따라 바뀌는 것 확인**

🗣
> "▶ 누르고 슬라이더를 끌어봅니다.
>
> **점수: 0 점. 점수: 37 점. 점수: 100 점.**
>
> **따라옵니다.**
>
> 버튼의 On Click 과 **똑같은 방식**으로 연결했어요. 다른 건 하나뿐입니다.
> **슬라이더는 값까지 넘겨준다.**"

🗣
> "이게 게임에서 어떻게 쓰이냐면요.
> 음량 조절, 밝기 조절, 캐릭터 만들기 화면의 키나 얼굴 조절.
> **전부 이 구조입니다.**"

 **주의 — 매우 중요**
- **Dynamic / Static 목록을 크게 확대**해서 보여주세요. 작아서 안 보입니다.

# **비프로그래머 대상 표현 치환표**

전 차시에 걸쳐 적용함.

| 쓰지 말 것 | 이렇게 말할 것 |
| :--- | :--- |
| 변수, 필드 | **입력 칸**, **값** |
| 메서드, 함수 | **동작**, **기능** |
| public / private | (언급하지 않음) |
| 클래스, 인스턴스, 참조 | **끌어다 놓은 것** |
| 컴포넌트 | **부품** (영어 이름은 필요할 때만) |
| 프로퍼티 노출 | **인스펙터에 보이게 하기** |
| 이벤트 구독, 콜백 | **~할 때 같이 실행되게 연결** |
| 컴파일 | **저장하면 Unity가 알아서 반영** |
| 매개변수 | **넘겨받는 값** (Dynamic 설명에만 한정 사용) |
| 상속 | (다루지 않음) |
| 프레임 | (다루지 않음) |
| 크로스 플랫폼 | **한 번 만들면 어디든 간다** |
| 렌더링 | **화면에 그리기** |
| 빌드 | **완성해서 내보내기** |
