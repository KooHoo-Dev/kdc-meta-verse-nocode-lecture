# **[00:03 ~ 00:08] EventSystem — 화면의 안내데스크**

🖥 **화면**: 교안 1번 표와 도식

🗣
> "17차시에 UI를 처음 만들 때, **Canvas 말고 하나가 더** 생겼던 거 기억나시나요?
> **EventSystem** 이라고 적혀 있었죠. 그때 '지금은 몰라도 됩니다' 하고 넘어갔습니다.
>
> **오늘 그 정체입니다.**"

🗣
> "건물에 **안내데스크**가 있다고 생각해보세요.
>
> 손님이 들어오면 안내데스크가 **누구를 찾는지 확인**하고, **맞는 사람에게 연결**해주죠.
> 안내데스크가 없으면? **아무도 못 만납니다.**
>
> EventSystem이 딱 그 일을 합니다.
> **마우스가 클릭한 자리에 무엇이 있는지 확인**해서, **그 물건에게 '눌렸다'고 알려줍니다.**
>
> 그러니까 **EventSystem이 없으면 화면의 어떤 것도 안 눌립니다.**"

🗣
> "그래서 Unity가 **UI를 만들 때 자동으로 하나 만들어주는** 겁니다.
> 씬에 **하나만** 있으면 되고요. 여러분이 직접 만드실 일은 거의 없습니다.
>
> 말로만 하면 안 와닿으실 테니, **일부러 지워보겠습니다.**"

   CubeSpinner → StartSpin / StopSpin / ChangeColor
⑧ Car 의 Target Color 에서 바꿀 색 고르기
⑨ Car 의 On Stopped → + → Car 드래그 → ChangeColor
⑩ ▶ 누르고 버튼 세 개 눌러보기

 **트러블슈팅 — 대표 두 개만**
- **"버튼이 패널 밖에 생긴다"** → Panel **이름 위에서** 우클릭해야 합니다.
- **"색이 안 바뀐다"** → `Target Color` 를 안 고른 경우입니다. 기본값이 현재 색과 같으면 변화가 없습니다.

# **비프로그래머 대상 표현 치환표**

전 차시에 걸쳐 적용함.

| 쓰지 말 것 | 이렇게 말할 것 |
| :--- | :--- |
| 변수, 필드 | **입력 칸**, **값** |
| 메서드, 함수 | **동작**, **기능** |
| public / private | (언급하지 않음) |
| 클래스, 인스턴스, 참조 | **끌어다 놓은 것** |
| 컴포넌트 | **부품** (영어 이름은 필요할 때만) |
| 프로퍼티 노출 | **인스펙터에 보이게 하기** |
| 이벤트 구독, 콜백 | **~할 때 같이 실행되게 연결** |
| 컴파일 | **저장하면 Unity가 알아서 반영** |
| 매개변수 | (다루지 않음) |
| 상속 | (다루지 않음) |
| 프레임 | (다루지 않음) |
| 레이캐스트 | **클릭이 닿는지 확인하기** |
| 크로스 플랫폼 | **한 번 만들면 어디든 간다** |
| 렌더링 | **화면에 그리기** |
| 빌드 | **완성해서 내보내기** |
