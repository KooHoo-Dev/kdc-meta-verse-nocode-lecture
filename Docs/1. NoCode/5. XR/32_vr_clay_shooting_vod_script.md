# **비프로그래머 대상 표현 치환표**

전 차시에 걸쳐 적용함.

| 쓰지 말 것 | 이렇게 말할 것 |
| :--- | :--- |
| 변수, 필드 | **입력 칸**, **값** |
| 메서드, 함수 | **동작**, **기능** |
| public / private | (언급하지 않음) |
| 클래스, 인스턴스, 참조 | **끌어다 놓은 것** |
| 컴포넌트 | **부품** (영어 이름은 필요할 때만) |
| 인터랙터 · 인터랙터블 | **잡는 쪽** · **잡히는 쪽** |
| 콜라이더 | **부딪히는 몸** |
| 렌더 모드 | **화면을 어떻게 그릴지** |
| 월드 스페이스 | **세상 안에 세우기** |
| 이벤트 구독, 콜백 | **~할 때 같이 실행되게 연결** |
| 프로퍼티 노출 | **인스펙터에 보이게 하기** |
| 컴파일 | **저장하면 Unity가 알아서 반영** |
| 매개변수 | (다루지 않음) |
| 상속 | (다루지 않음) |
| 프레임 | (다루지 않음) |
| 빌드 | **완성해서 내보내기** |
